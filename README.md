## 🛠️ Project Tech Stack

This website is built using frontend web technologies:

* **Core Framework:** React 18 (`react`, `react-dom`)
* **Programming Language:** TypeScript
* **Styling & Layout:** SASS / SCSS, CSS3
* **UI Components & Icons:**
  * Material-UI (`@mui/material`, `@mui/icons-material`)
  * FontAwesome (`@fortawesome/react-fontawesome`)
  * React Vertical Timeline (`react-vertical-timeline-component`)
* **Animations:** Framer Motion (`framer-motion`)
* **Build & Deployment:** `react-scripts`, GitHub Pages (`gh-pages`)

---

## 📌 Features

* **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
* **Interactive Project Showcase:** Cards highlighting personal projects with links to GitHub repositories.
* **Career History Timeline:** Chronological vertical timeline of work experience.
* **Expertise & Skills Grid:** Categorized technology chips and skill cards.
* **Direct Contact:** Quick access to GitHub and LinkedIn profiles.

## 🚀 Local Development Setup

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Hassan-Nfissi/My-portfolio.git

# 2. Navigate into the project folder
cd My-portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm start
```
Open **`http://localhost:3000`** in your browser.
